# Privacy

Slopocalypse is a free, open-source game. There are no accounts, no ads, no analytics and no tracking. This page explains what the game and its servers keep about you, in plain words.

_Last updated: 10 November 2026._

## On your computer

- **Your profile** (`profile.json` in the game's user folder): the player name you picked and a random key the game makes once per install. The key lets a server recognise you and give you back your gear. Nobody else has it.
- **Settings, logs and performance logs** stay on your computer, in the same folder. Nothing is sent anywhere unless you send it yourself, for example by attaching a log to a bug report.
- **Solo play** runs a small server on your own computer. Its save stays there.

## On a server you join

Whoever runs a server keeps a save file on it. For each player it holds:

- your player name and the random key from your profile
- your progress: where you were, health, gear and tokens
- when you first joined and last saved

The server also writes logs of connections and of what happens in the game, such as joins, leaves, missions and kicks, so its owner can fix problems. A future version keeps a journal of game events for the same reason.

Each server is run by its owner, not by the Slopocalypse project. The project's own server, run by the maintainer, keeps only what is listed here. It uses it only to run the game and never sells or shares it. To have your data removed from it, open an issue on GitHub or contact the maintainer, and your save will be deleted. For any other server, ask its owner.

## Discord

If you turn on Discord Rich Presence in the game's settings, the game tells the Discord app on your computer what you are doing, for example "Operation Rusty Lantern · Clean Sweep". Discord shows that on your profile under Discord's own privacy policy. If you also allow joining, the address of the server you are on is shared so friends can join. With it off (or Discord closed) nothing is sent to Discord.

## Children

The game has no accounts and does not knowingly collect anything beyond what is listed above.
